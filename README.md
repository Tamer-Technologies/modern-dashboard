# Dashboard

A responsive dashboard built to practice CSS Grid and responsive design.

## About

This is a learning project where I practiced building a dashboard layout that works on different screen sizes. I mainly wanted to get practice at CSS Grid and responsive design.

## What I Learned

While building this project, I learned:

- CSS Grid for layout (used it before but wanted to practice it more)
- Making websites responsive
- Chart.js for charts
- How to organize my environment better
- Making a single-page app without frameworks (changing content without going to new pages)
- Creating dynamic content from JSON data
- NPM
- JavaScript modules
- Webpack

## Technologies Used

- HTML

- JavaScript
- Chart.js
- Webpack
